# RAG 文档问答 Demo

## 功能

- 上传 PDF、TXT、Markdown 文档
- 保留文件名和 PDF 页码
- 按 token 切块
- 使用本地嵌入模型生成向量
- 使用 FAISS 检索相关片段
- 调用 DeepSeek 官方 API 回答问题
- 展示和检查来源编号
- 保存知识库并在重启后恢复

## 环境准备

使用 Python 3.11 和 uv。

安装锁定的项目依赖：

uv sync --locked

## 配置

在项目根目录的 .env 中填写：

DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-flash

不要提交 .env。

本地需要已有的模型缓存：
sentence-transformers/all-MiniLM-L6-v2

## 启动

uv run streamlit run app.py --server.fileWatcherType none

## 验证持久化

uv run python test_persistence.py

## 当前限制

- 一次管理一份文档，新建知识库会替换当前知识库。
- 默认嵌入模型主要面向英文，中文检索效果需要评估。
- 扫描 PDF 需要先做 OCR。
- 每个问题独立处理，没有多轮对话记忆。
- 来源编号合法，不代表答案中的事实一定正确。
- 更换嵌入模型后，需要重新建立知识库。
